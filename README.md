# Calculator.py
Scientific calculator a python calculator that supports basic and scientific operations. 
Features: addition, subtraction, multiplication, division, power, square root , rounding, trigonometric functions (sine, cosine, tangent) absolute value, and logarithms (base 10 and natural log)
How to run: run the file in python 3: calculator.py, then choose an operation from the menu and enter your numbers.
fun feature: I added cat emojis to each answer with snarky/funny comments because even calculators deserve a personality.
